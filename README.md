# CareerPilot 

CareerPilot is a career management platform designed to help users plan their career paths, track job applications, identify skill gaps, and manage their professional growth.

## Tech Stack

- Next.js
- React & TypeScript
- Tailwind CSS
- PostgreSQL & Prisma
- Better Auth
- TanStack Query

## Features

- Career-focused onboarding
- Job application tracking
- Career planning and skill gap analysis
- Authentication with email/password and OAuth
